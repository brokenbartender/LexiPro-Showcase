# LexiPro

LexiPro is the umbrella engineering standard operated by Broken Arrow Entertainment LLC. Work under this name states only what the record supports, and withholds the rest.

**Live site:** [lexipro.online](https://lexipro.online)

## Current products

### LexiPro

The engineering standard, and the public site at [lexipro.online](https://lexipro.online). Operated by Broken Arrow Entertainment LLC. ShiftEdge and Holdfast are separate products under that standard. This repository is the showcase site. It is not the application source for either product.

### ShiftEdge

A Michigan tipped-worker wage and shift-tracking ledger, shipped as a standalone progressive web app (Next.js and Capacitor).

**Live app:** [shiftedge.app](https://shiftedge.app)

ShiftEdge is for planning the week, understanding pay, and checking a paystub, with the record kept on the worker's device. Wage tracking follows Michigan rules for tipped work. It is a record for the worker to review. It is not legal advice.

ShiftEdge is its own codebase. Holdfast is a separate platform, and the two do not share a code dependency.

### Holdfast

A private-development Michigan forensic evidence and pro se case platform. Holdfast is one full-stack application, not a catalog of standalone public packages.

Work underway includes:

- Evidence vault
- Hash-linked audit chain
- Chronology
- Proof-packet export
- PII scanning

Holdfast is separate from ShiftEdge. The two products do not share a code dependency.
