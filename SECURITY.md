# Security Policy

## Supported Versions
Only the latest major release of the Sovereign OS kernel and LexiPro frontend are supported with security updates.

## SL5 Air-Gap Compliance
The core Sovereign OS operates under strict SL5 compliance. No unauthorized external egress is permitted. The Hestia Egress Guard actively sanitizes outbound payloads.

## Reporting a Vulnerability
If you discover a potential bypass of the Hestia Egress Guard or a vulnerability in the LexiPro frontend, please DO NOT open a public issue. 
Email details to admin@lexipro.online. We pledge to review all reports within 48 hours.
