# Security policy

This repository is the public showcase site for LexiPro ([lexipro.online](https://lexipro.online)), operated by Broken Arrow Entertainment LLC.

LexiPro is the umbrella engineering standard. [ShiftEdge](https://shiftedge.app) is a separate Michigan tipped-worker wage and shift-tracking application. Holdfast is a separate platform in private development. Report vulnerabilities in those products to the same address, and name the product in the subject line.

## Reporting a vulnerability

If you find a security vulnerability in this website, do not open a public GitHub issue.

**Report privately to:** [partnerships@lexipro.online](mailto:partnerships@lexipro.online)
**Subject line:** `[SECURITY]` followed by a short description

Include:

- What you found
- Steps to reproduce
- The impact you expect
- How to reach you, if you want credit or a follow-up

Reports are acknowledged within 48 hours. There is no bug bounty program. Researchers are credited in notes about the fix unless they ask to stay anonymous.

## Out of scope

- Social engineering of Broken Arrow Entertainment LLC personnel
- Denial of service against lexipro.online
- Automated scanner output with no manual confirmation
- Issues in third-party services this site links to (report those to the vendor)
